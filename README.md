# knoQ Reminder

Simple reminder of events in the [knoQ](https://github.com/traPtitech/knoQ) service.

## 🌠 Features

### Ahead reminder

Sends reminders of upcoming events a specified number of minutes before they start.

### Daily reminder

Sends a daily reminder of today's events at a specified time.

### Support for various services

In addition to the [traQ](https://github.com/traPtitech/traQ) service, this app also supports sending reminders via Discord and Slack.
